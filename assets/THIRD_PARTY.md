# Recursos visuais e bibliotecas

- **Fundo:** “Night sky”, Jack B, 30/06/2018, [Unsplash](https://unsplash.com/photos/a-night-sky-with-a-few-stars-in-it-bOfCH9TnRg4). Arquivo em `backgrounds/night-sky.jpg`; usado com sobreposição escura. [Licença Unsplash](https://unsplash.com/license), consultada em 28/09/2026.
- **Fonte:** Montserrat, projeto de Julieta Ulanovsky e colaboradores, [Google Fonts](https://github.com/google/fonts/tree/main/ofl/montserrat). Arquivo variável original em `fonts/Montserrat-Variable.ttf`; licença SIL OFL em `fonts/OFL.txt`. As instâncias estáticas usadas nas figuras são geradas a partir desse arquivo.
- **Three.js 0.180.0:** distribuição oficial via jsDelivr, arquivos de `build/` e `examples/jsm/controls/OrbitControls.js` em `vendor/`. Licença MIT em `vendor/THREE-LICENSE.txt`. O exportador incorpora os módulos ao HTML e ajusta apenas a resolução do import do módulo principal para o import map.
- **Plotly.js:** incorporado pelo pacote Python Plotly; seu cabeçalho de licença é preservado no HTML.

O fundo é decorativo; as estrelas não representam dados físicos. A esfera, seus pontos e vetores são geometria gerada por código. Referência matemática: [IBM Quantum — Bloch sphere](https://quantum.cloud.ibm.com/learning/en/courses/general-formulation-of-quantum-information/density-matrices/bloch-sphere).
